# Getting help

These packages are maintained by a small team at What Works alongside our day-to-day work, so we answer as time allows and can't promise response times.

| You want to…                                                 | Go to                                                                                                                                                                                |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ask how to use a package, or float an idea                   | [Discussions](https://github.com/what-works-global/payload-packages/discussions)                                                                                                     |
| Report a bug                                                 | An [issue](https://github.com/what-works-global/payload-packages/issues/new/choose) using the bug report form. See [CONTRIBUTING.md](CONTRIBUTING.md) for what makes a report useful |
| Request a feature                                            | An issue using the feature request form, or a discussion if it's still a rough idea                                                                                                  |
| Report a security vulnerability                              | **Not a public issue.** Follow [SECURITY.md](SECURITY.md)                                                                                                                            |
| Get help with Payload, Next.js or another upstream framework | That project's own docs and community, e.g. [Payload docs](https://payloadcms.com/docs)                                                                                              |

Before posting, check the package README and search existing issues and discussions. Someone may already have asked.

For paid work with What Works, see [whatworks.com.au](https://whatworks.com.au).
